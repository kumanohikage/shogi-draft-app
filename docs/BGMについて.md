# BGM について

BGM はアプリに入っていません。使う人がそれぞれダウンロードして入れてください。

## 入れ方

- 管理画面の「進行」タブで「曲を追加」を押し、音声ファイルを選ぶ
- または、メニューの「ファイル → BGMフォルダを開く」で開いたフォルダに曲を置く

使えるファイル: mp3 / ogg / wav / m4a / aac / flac

## なぜ同梱しないか

おすすめ曲は OpenTracks（旧 DOVA-SYNDROME）の曲です。音源利用ライセンスで、音源を配布することが禁止されています。エンドユーザーが音声ファイルを取り出せる状態での利用も禁止です（禁止事項 7・8）。アプリに入れて配ると、これに当たります。

配信の BGM として流すことは許可されています。利用料もクレジット表記も不要です。

- 音源利用ライセンス: https://opentracks.com/help/articles/license/

## 効果音について

カードがめくれる音、競合の音、交渉権確定の音、チーム表の音は、アプリの中で合成しています。音源ファイルを使っていないので、ライセンスの心配はありません。
